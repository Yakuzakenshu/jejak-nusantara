# Jejak Nusantara

Game petualangan dan fotografi 3D berlatar Nusantara (IKN), Kalimantan Timur. Dimainkan langsung di browser.

- Pilih karakter Laras atau Bima, lalu potret tujuh tempat dari Kampung Sepaku sampai Istana Garuda.
- Foto dinilai ★ sampai ★★★, ada enam momen langka, lompat drone lewat peta, serta siang, malam, dan hujan.

Statistik pemain dicatat secara anonim (tanpa nama, tanpa cookie) lewat GoatCounter.

Karakter 3D: model contoh dari proyek three.js (Mixamo dan Ready Player Me).
